# IIMM Ayodhya Website

A responsive and modern website developed for **IIMM Ayodhya**.  
The website provides information about the institute, its activities, programs, registration, and contact details.

## Live Repository

GitHub Repository:

https://github.com/ayushsinghcoder11/IIMM-Ayodhya-website

---

## About the Project

The **IIMM Ayodhya Website** is a frontend web project designed to provide an attractive, user-friendly, and responsive online presence for IIMM Ayodhya.

The website includes multiple pages and sections to help visitors easily access information about the institute and its services.

---

## Features

- Home Page
- About Us
- Contact Us
- Login Page
- Registration Page
- Responsive Design
- Mobile-Friendly Layout
- Image Gallery/Visual Content
- Easy Navigation
- Bootstrap-based UI
- Multiple HTML Pages
- JavaScript-based interactions
